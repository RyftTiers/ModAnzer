ModAnzer

· Screenshare tool
Read-only
Not a hacking or malware tool. It only reads, and it's open source.

It checks your mods, the running game and Windows' records, then shows the results on screen. Only if you press Enter at the end (or Get code in the app) is a summary sent, and you get a short code to give RyftTiers staff.

Staff look the code up with /ssresult in the RyftTiers Discord.

What it checks

· 4 modes

1Mod Analyzer

Finds every mods folder (vanilla, CurseForge, Modrinth, Prism, Lunar, Dawn, Fast Client and more), checks each mod against Modrinth, Megabase and CurseForge, and searches unknown mods for cheat module names. It ends with a list of every cheat and which instance it was in.

2Injection Checker

Runs while the game is open. It checks the launch options and loaded DLLs, reads Minecraft's memory (read-only) for cheat names and hidden manual-mapped programs, then watches live for injected DLLs, swapped mods and programs started from Downloads, Desktop or Temp.

3System Check

Looks for traces: programs that ran and were deleted (BAM, Prefetch), cheat tools, cleared event logs and PowerShell history, logging services turned off, USB drives, the Recycle Bin, recent downloads, virtual machines and alt account names.

4Full Screenshare

Runs all three in a row. For options 2–4 it asks for administrator rights so it can read Windows' records; the player can say no.

RyftTiers

It does

Allowed
  • Read your mods folders and fingerprint the .jar files
  • Look fingerprints up on Modrinth, Megabase and CurseForge
  • Read Minecraft's loaded DLLs and memory, without changing anything
  • Read Windows' records of programs that ran, logs and USB drives
  • List Minecraft account names (never tokens or emails)
  • Show everything on screen
RyftTiers

It doesn't

Never
  • Upload your files. Only mod fingerprints, plus a results summary if you press Enter to send it
  • Read passwords, tokens, emails, Discord or browser data
  • Change game memory or inject into any program
  • Change, move or delete files, or install anything
